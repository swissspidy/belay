    How it works

    Each message is embedded with bge-small-en-v1.5 through transformers.js. A small classifier on the embeddings (nearest neighbors first, a softmax layer once it has enough examples) predicts the team. Its score becomes a confidence by Platt scaling, fitted on how it did on messages it had not seen yet, so the threshold keeps meaning "accept when at least this likely right". Below the threshold the message goes to the cloud, and the cloud's answer becomes a training example. Explore also sends a share of confident messages to the cloud, to keep checking the local answers.

    The cloud here is simulated with the dataset's labels (1,500 messages from the Bitext customer support dataset, CDLA-Sharing-1.0), and each call is priced at $0.0020, what Claude Opus 5.5 cost per message in the ticket-triage calibration. Only embeddings are stored, never the text. 

    import { task, fetchAdapter } from '@swissspidy/belay-core';
import { learnedClassifier, transformersEmbedder, indexedDbStore } from '@swissspidy/belay-learn';

const triage = task({
  name: 'ticket-triage',
  schema: { type: 'categorical', options: ['account', 'billing', 'order', 'shipping', 'feedback'] },
  local: learnedClassifier({ embedder: transformersEmbedder(), store: indexedDbStore() }),
  cloud: fetchAdapter({ url: '/api/belay' }),
  threshold: 0.9,
  explore: 0.05,
});

    Belay is open source (Apache-2.0): github.com/swissspidy/belay. The learned classifier is @swissspidy/belay-learn.
